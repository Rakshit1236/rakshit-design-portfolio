# Rakshit Design Portfolio

A React portfolio focused on selected graphic design work.

## Local development

```sh
npm ci
npm run build
```

The production-ready static site is generated in `dist/`. Upload the contents
of that folder to a static web host, or let the GitHub Pages workflow deploy it.

## GitHub Pages

Push to the `main` branch to build and deploy the site. The workflow builds
with Node.js 20 and publishes the contents of `dist/`.
